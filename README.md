# Royal Enfield Combined Showcase & Hero Scroll Animation

A combined showcase experience for Royal Enfield combining the 300-frame mountain run scroll animation directly inside the hero section with the full product showcase website.

---

## 🚀 Live Localhost Link

The web application is live and running at:
**[http://localhost:3000](http://localhost:3000)**

---

## 🌟 Architecture & Sections

1. **Hero Section (Scroll Animation)**:
   - Full-width sticky canvas seamlessly integrated at the top of the page.
   - Smoothly scrubs through all 300 frames of the mountain run as you scroll.
   - Bottom gradient gracefully blends into the Heritage section.
   - Minimal floating badge and scroll prompt.

2. **Heritage & Storytelling Section**:
   - "A Century of Pure Motorcycling" editorial narrative.
   - Madras handcraft pinstriping craft showcase.
   - Archival milestones (1932 London Sloper engine, 1955 Indian Armed Forces adoption, 2024 J-Series reimagination).

3. **Key Features & Mechanical Specs Grid**:
   - 4-card interactive Bento Matrix:
     - J-Series 349cc Heart (27 Nm @ 4,000 RPM)
     - Single-Piece Contour Ergonomic Saddle (805mm)
     - Dual-Channel ByBre ABS & 300mm front rotor
     - Harris Performance Twin Downtube Spine Frame
   - Engineering spec sheet download banner.

4. **Colorways & Interactive Customizer**:
   - Real-time interactive variant selector:
     - **Black Gold Edition** (24k-inspired Madras lines)
     - **Military Red** (Post-war service vermilion)
     - **Forest Green Heritage** (Redditch British green)
     - **Standard Maroon** (Classic Madras heritage)
   - Live price and 3D badge finish updater with animated bike transition.

5. **Sensory Experience & Test Ride Reservation**:
   - Direct booking form with instant validation and confirmation message.

6. **Footer**:
   - Redditch • Chennai heritage branding, full directory links, and customer concierge hotline.
